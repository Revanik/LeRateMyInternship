# E1 Internship Reviews and Moderation
Students can create and interact with internship reviews.

## US1 Create Account:
As a student, I want to create my own account, so that I am able to track saved internship postings and reviews that I have made.  
FR: FR3, FR4  
Priority: Must  
MVP: yes  

-[] The student can register their email and create an account.  
-[] A student is able to access their account by logging in with their correct credentials.  
-[] A student is prompted to reenter their login information if it is incorrect.  

## US2 Create Review:
As a student, I want to post a review about an internship I completed, so that I can share my experience with other students.  
FR: FR1  
Priority: Must  
MVP: yes  

-[] The student can create a review regarding a specific internship.  
-[] The student can post the review regarding the specific internship.  

## US3 Rate Internship:
As a student, I want to rate my internship experience 1-5 overall or by specific categories, so that other students can understand how I felt about my experience.  
FR: FR6  
Priority: Must  
MVP: yes  

-[] The student can rate the internship on an overall scale of 1-5.  
-[] the student can rate the internship by specific categories on a scale of 1-5 if they choose not to rate the internship overall.  

## US4 Edit Review:
As a student, I want to edit a review that I previously posted, so that I can correct any mistakes or update information about my internship.  
FR: FR5  
Priority: Should  
MVP: yes  

-[] The student can edit a previously posted review.  
-[] The student can post their updated version of the review.  

## US5 Flag Review:
As a student, I want to flag a review based on accuracy and helpfulness to allow myself and other students to track the most helpful reviews.
FR: FR10  
Priority: Should  
MVP: no  

-[] The student can flag a review based on whether the review was accurate and helpful.  

# E2 Searching for Internships:
Students can search for internships in ways they personally desire.

## US6 Browse Reviews: 
As a student, I want to browse internship reviews in order of newest posting, so that I can read other students’ recent experiences and ratings.  
FR: FR13, FR2  
Priority: Should  
MVP: yes  

-[] A student can search internship reviews in order of newest posting.  
-[] The system displays internship reviews in order of newest posting.  

## US7 Filter Internships:
As a student, I want to sort the internships I view based on categories such as location, compensation, major, and most-recently posted, so that I am only presented with internships that, I decide, are relevant to me.  
FR: FR2  
Priority: Must  
MVP: no  

-[] A student can filter internships by location, company, time posted, compensation, and major.  
-[] The system displays only internships with the selected filters.  
-[] A student can remove filters to view the original search results.  

## US8 Search Specific Internships:
As a student, I want to search for a specific internship posting, so that I am immediately able to access that particular internship’s details and reviews that other students have made about it.  
FR: FR8  
Priority: Should  
MVP: yes  

-[] A student can enter a search term to find internship postings.  
-[] The system displays internship postings that match the entered search term.  
-[] A student can select a search result to view the internship’s details and available reviews.  

## US9 Recommend Internships:
As a student, I want to be exposed to new internships that are relevant to me, so that I am able to learn about and apply to more internships.  
FR: FR12  
Priority: Could  
MVP: no  

-[] The system provides internship recommendations based on the student’s recently viewed and past internships.  
-[] A student can view the recommended internship listings.  
-[] A student can select a recommendation to view its details.  

## US10 View Internships by Company: 
As a student, I want to search for internships at a specific company, so that I can view all available opportunities from that specific company.  
FR: FR8, FR2  
Priority: Could  
MVP: yes  

-[] A student can search for internships by entering a company name.  
-[] The system displays all available internship postings under the company’s name.  
-[] A student can select an internship from the results to view its details.
